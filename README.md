## 🎯 How to Play

1. Choose either:

   * 🪨 Rock
   * 📄 Paper
   * ✂️ Scissors

2. The computer will randomly select its move.

3. Results are determined as follows:

| Player      | Computer    | Result |
| ----------- | ----------- | ------ |
| Rock        | Scissors    | Win    |
| Rock        | Paper       | Lose   |
| Paper       | Rock        | Win    |
| Paper       | Scissors    | Lose   |
| Scissors    | Paper       | Win    |
| Scissors    | Rock        | Lose   |
| Same Choice | Same Choice | Draw   |

4. Score updates automatically after each round.
